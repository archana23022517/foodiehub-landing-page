# 🍔 FoodieHub - Restaurant Landing Page

A modern, fully responsive restaurant landing page built with HTML, CSS, and Vanilla JavaScript. This project was created as Task 1 for the Codveda Technologies Front-End Development Internship.

## 🚀 Features
- **Responsive Design:** Mobile-first approach using CSS Grid and Flexbox (perfect on mobile, tablet, and desktop).
- **Semantic HTML5:** Accessible and SEO-friendly structure.
- **Shopping Cart:** Add items to cart, update quantities, and calculate total price dynamically.
- **Local Storage:** Cart items and Dark Mode preference are saved even after refreshing the page.
- **Dark Mode Toggle:** Switch between light and dark themes.
- **Menu Filter:** Filter food items by category (Pizza, Burger, Biryani, etc.).
- **Scroll Animations:** Smooth reveal animations using Intersection Observer.
- **Modern UI:** Gradient text, floating cards, toast notifications, and smooth scrolling.

## 🛠️ Tech Stack
- **HTML5** (Semantic tags)
- **CSS3** (Grid, Flexbox, Media Queries, Variables, Animations)
- **JavaScript** (DOM Manipulation, LocalStorage, Intersection Observer)

## 📁 File Structure
- `index.html` - Main HTML document
- `style.css` - All styling and responsive media queries
- `script.js` - Cart logic, theme toggle, animations, and interactivity
